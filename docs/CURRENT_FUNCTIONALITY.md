# Baby Daily - Current Functionality

## Session Management

### Active Session

- Track multiple events within a single wake/sleep session
- Start time (wake-up time) tracking
- End time (sleep time) tracking
- Photo capture for the session
- Real-time session duration display

### Event Types

1. **Milk Entries**
    - Record amount in ml
    - Timestamp for each entry
    - Multiple entries per session

2. **Pee Events**
    - Timestamp for each event
    - Multiple entries per session

3. **Poop Events**
    - Timestamp for each event
    - Multiple entries per session
    - Photo capture option

4. **Vitamin Section**
    - Vitamin taken or not taken during this session

### Session History

- Chronological list of all closed sessions
- Sleep duration calculation between sessions
- Session editing capabilities
- Visual sleep duration indicators between sessions
- Photo viewing support
- Excel export functionality

## Analytics

### Statistics Overview

1. **Total Sessions**
    - Count of sessions
    - Average sessions per day

2. **Milk Statistics**
    - Total milk intake
    - Average milk per session
    - Detailed view of all milk entries
    - Timeline of milk intake

3. **Sleep Statistics**
    - Total sleep time
    - Average sleep between sessions
    - Detailed sleep timeline
    - Session durations

4. **Event Totals**
    - Total pee events
    - Total poop events
    - Total milk entries

### Detailed Analytics

1. **Events per Session**
    - Average pee events
    - Average poop events
    - Average milk feeds

2. **Sleep Analysis**
    - Average sleep duration between sessions
    - Sleep pattern visualization

3. **Milk Analysis**
    - Average milk per feed
    - Feed timing patterns

4. **Activity Patterns**
    - Most active times detection
    - Smart time window analysis
    - Activity heat map by hour
